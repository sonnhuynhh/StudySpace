# Ảnh minh họa

Ba ảnh `room-study.png`, `room-lab.png`, `room-library.png` được tạo bằng ImageGen cho project này. Đây là ảnh minh họa AI, không phải ảnh cơ sở vật chất thật của trường. Các phòng cùng loại dùng chung ảnh để giữ dữ liệu mẫu nhỏ và có thể chạy ngoại tuyến.

Các icon ứng dụng còn lại được cung cấp bởi template Expo blank-typescript. Icon trong giao diện dùng Ionicons qua `@expo/vector-icons`.
